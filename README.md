## 🚀 **Cómo empezar localmente**

### **Requisitos**
- Git (opcional: Node.js para herramientas de construcción, si agregas alguna)
- Un navegador moderno (Chrome, Firefox, Edge)

### **Pasos**
```bash
# 1️⃣ Clonar el repositorio
git clone https://github.com/JulioHidalgo/JulioHidalgo.git

# 2️⃣ Entrar al proyecto
cd JulioHidalgo

# 3️⃣ Abrir en VS Code o un editor de tu preferencia
code .   # si usas VS Code

# 4️⃣ Abrir index.html en el navegador para ver el portafolio
